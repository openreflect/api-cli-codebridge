OpenReflect public framework

Stable API contracts for local model CLIs.

API CLI Codebridge defines the adapter layer between API-first clients and command-line model tools with their own auth, process behavior, session state, and streaming shape.

View repository Run the validator

Why it exists

Local CLIs are useful. Runtime contracts need to be predictable.

The problem

Coding-model CLIs often provide the most practical access path for authenticated or subscription-backed tools. Agent runtimes usually need a smaller, steadier provider interface.

The shape

Codebridge keeps each adapter explicit: manifest, invocation, health check, model list, streaming support, and session behavior.

Core idea

A thin bridge, not a hidden runtime.

Each adapter owns deterministic translation: request shape, process invocation, session binding, health checks, and response normalization.

Scope

What Codebridge manages

Adapter manifests

Public-safe configuration for commands, models, capabilities, and health checks.

Contract checks

Deterministic validation before any private credential or live deployment is involved.

Normalization

A path toward consistent model listing, chat completion, streaming, and session semantics.

Quickstart

Validate the synthetic adapter manifest.

git clone https://github.com/openreflect/api-cli-codebridge.git
cd api-cli-codebridge
python3 scripts/validate_manifest.py examples/adapter-manifest.example.json

Expected result: MANIFEST_OK

Current status

Early public framework, deliberately small.

The repository currently contains the public-safe project shape, a synthetic adapter manifest, a deterministic validator, and this static documentation site. Private deployment paths, credential references, live routing policy, and original operational wrappers belong in private downstream workspaces.
